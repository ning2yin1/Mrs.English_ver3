# Mrs. English Ver.3 — 5-screen UI kit

5画面の素材・完成モックアップ・配置データ・実装指示・再構成比較をまとめた、Codexへ渡すための制作キットです。ゲーム本体の実装、GitHub操作、公開は行っていません。

## 最初に見るファイル

1. `qa/all_screens_preview.jpg`：5画面の再構成一覧。
2. `mockups/`：ユーザーが決定した完成モックアップ5枚。
3. `docs/CODEX_IMPLEMENTATION.md`：今回の5画面全体の実装指示書。
4. `docs/LAYOUT_SPEC.md`：座標・サイズ・描画順・タップ範囲。
5. `docs/QUALITY_REPORT.md`：比較結果と残る違い。
6. `layouts/screen_index.json`：各画面の素材・仕様・プレビューへの入口。

## 構成

- `home_approved/`：承認済みホームキットを**ファイル内容を変更せず**収録。
- `assets/title/`：タイトルのロゴ、TAP帯、写真レイヤー。
- `assets/nickname/`：上部バー、半透明パネル、入力枠、決定ボタン、写真レイヤー。
- `assets/member/`：上部バー、選択／未選択カード枠、決定ボタン、写真レイヤー。
- `assets/background/`：上部バー、一覧パネル、プレビュー枠、選択枠、決定ボタン、写真レイヤー。
- `assets/icons/`：戻る、決定矢印、チェック、写真アイコン。
- `assets/photos/`：人物写真の独立した切り抜き、照合用のサムネイル／プレビュー写真、元のTOP.jpg。
- `assets/fonts/`：固定ラベルの字形を収録した限定フォント。変更可能な文字要素として使う。
- `layouts/`：JSON・CSVの配置仕様、画像素材一覧、別途受領する背景画像の対応表。
- `qa/`：4画面の再構成・差分・透過一覧・検証結果。ホームの検証一式は `home_approved/qa/`。

既存ホームの指示書には「残り4画面は未制作」といった当時の記述があります。履歴を維持するため原文を保存しています。**今回の全体範囲は `docs/CODEX_IMPLEMENTATION.md` を優先**し、ホームの見た目・座標・素材は元の仕様をそのまま使用してください。

## 背景画像

背景22枚の元データは、このZIPだけで揃う前提ではありません。ユーザーが別途渡す `backgrounds.zip` を受領し、`layouts/external_backgrounds.json` のIDに対応させてください。

サムネイルの小画像は完成モックアップとの照合用です。モックアップには一部の写真内容と番号が元データ順と一致しない箇所があります。実装では別途の元写真をIDどおりに使い、枠・配置・ボタンの見た目を維持してください。小さな照合用画像をホーム背景へ引き伸ばして使用しないでください。

## 精度の扱い

元画像のレイヤーがないため、文字の下の模様・薄い発光・半透明パネルの分離には補間・解析を使用しています。画像全体を操作不能な画面として貼る構成にはしていません。動的文字はPNGラベルではなく文字とフォントへ分離しました。

元写真と人物はAIで再生成していません。再構成の画素比較は収録していますが、iPhone／ブラウザーでの実装後の表示検証は、後のCodexでの作業です。
