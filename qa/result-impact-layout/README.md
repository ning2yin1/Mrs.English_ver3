# リザルト確定演出の配置検証

- STAGE CLEAR → 評価 → TOTAL SCORE → スコア → 正解数・正答率の順に専用の縦領域へ配置。
- 1536×710、844×390、667×375で、最大1.12倍の衝撃演出を含む各フレームを検証。
- iPhone相当では左右47px・下21pxのセーフエリアを指定。
- TOTAL SCOREとスコアの間は12px以上。通常リザルトへの移動中は退場する文字を隠し、交差を回避。
- 通常リザルトは修正前コミット5ee8730と同条件のスクリーンショットが完全一致。
- 発光・衝撃波を保持。検証ページはメモリ内のサンプルのみを使用し、localStorageに変更なし。
- `npm run test:result-layout`（開発サーバーを4175で起動）で再検証可能。
- 実機のiPhone Safari／PWAでの検証は未実施。

`*-impact-peak.png` は衝撃最大時、`*-final.png` は通常リザルト。各フレームの座標は `results.json` に保存。
