# Home UI quality verification

## 対象と方法

ユーザー添付の1844×853pxのホーム画像のみを使用。元画像からUIの座標を読み取り、PNGの装飾面と独立アイコンを実際に重ね、フォントによる文字を別レイヤーで描画しました。比較画像はPillowで生成しています。ゲーム・ブラウザー・iPhoneでの動作テストは行っていません。

今回は人物・背景の再生成を行っていません。文字のない装飾面は、元画像の文字／アイコンがあった範囲を補間し、元の縁・陰影・グラデーションを残して制作しました。アイコンは元画像からアルファを求めて分離しています。既成アイコンライブラリは使用していません。

## 測定結果

| 確認項目 | 結果 |
|---|---|
| 基準サイズ | 1844×853pxで一致 |
| 文字なし装飾PNG | 9枚：上部4枚、下部5枚 |
| 独立透過アイコン | 10枚 |
| 中央写真の維持 | Y=100〜729の全画素は元画像と完全一致 |
| 全体のRGB平均絶対差 | 0.6003／255 |
| 上下UI帯だけのRGB平均絶対差 | 2.5351／255 |
| いずれかの色成分の差が16を超える画素 | 画面全体の約0.842％ |
| 透過 | 全19パーツをRGBAとして保存し、透明画素を持つことを確認 |
| 動的文字の焼き込み | 装飾PNG・アイコンPNGに動的な名前／数値／ラベルを残さず、再構成時に別描画 |
| タップ領域 | 全7領域をJSON・CSVに記録。動作は後の実装対象 |

全画面の数値は背景領域が大きいほど小さくなります。この値をそのまま「UIが99％一致」などの再現率に読み替えないでください。上下UIだけの差と拡大比較も合わせて確認してください。

## 元画像と異なる部分

1. **文字**：元フォントは不明です。名前・数値・通常ラベルは手元の近似フォントから比較選定しました。Readyは元のR/e/a/d/yの字形を輪郭化した専用TTFで再現し、画像ラベルにはしていません。字の輪郭・影・アンチエイリアスには差があります。
2. **隠れていた装飾面**：元の文字やアイコンの下は画像から取得できません。周辺の色を補間しています。そこに元から存在した模様を正確に復元したものではありません。
3. **輪郭**：切り落とした角・細い縁には、元写真との合成状態から分離する際の約1〜数pxの差があります。透過一覧と4倍差分にその差が見えます。
4. **背景レイヤー**：人物が見える中央は完全保持しています。元UIに隠れていた写真の部分は周辺の写真行で埋めており、元の自然な写真そのものではありません。別背景への切り替えでは提供された元写真を使います。

したがって、この成果物は**ホーム画面の高精度な確認用素材案**です。完全な画素一致やiPhone実装後の同一表示を保証する結果ではありません。採用確認後に残り4画面へ進めます。

## 比較ファイル

- `home_reference.png`：元画像。検証専用で、実装用背景に使用しない。
- `home_reconstructed.png`：納品PNGと別描画の文字による再構成。
- `home_difference.png`：絶対差。黒い部分は一致。
- `home_difference_x4.png`：差を4倍明るくした確認用画像。
- `home_overlay_50.png`：元画像と再構成を50％ずつ重ねた画像。
- `hud_comparison.png`：上が元画像、下が再構成。上下UIを並べて文字・縁を比較。
- `asset_contact_sheet.png`：透過PNGを市松模様の上に並べた一覧。
- `quality_report.json`：測定値・フォント比較・透過検査の詳細。
- `restoration_regions.json`：元文字やアイコンを除去した範囲の記録。
