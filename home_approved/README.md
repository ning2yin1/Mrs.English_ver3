# Mrs. English Ver.3 — Home UI asset review kit

このZIPはホーム画面だけの承認用素材です。残り4画面の素材は含めていません。ゲーム本体の実装・GitHub操作・公開は行っていません。

まず `qa/home_reconstructed.png` を確認してください。実際に納品するPNGと、画像に焼き込まない文字を重ねて作った再構成画像です。

## 内容

- `assets/home/`：文字とアイコンを取り除いた上部バー4枚・下部ボタン5枚。
- `assets/icons/`：元画像から独立させた透過PNG10枚。
- `assets/fonts/`：比較して採用した近似フォント、Ready専用の字形フォント、ライセンス情報。
- `assets/backgrounds/`：見本の背景写真レイヤーと、提供されたbg-01の元写真。
- `spec/home_layout.json`：座標・サイズ・重なり順・文字・タップ範囲・遷移先。
- `spec/home_layout.csv`：表計算で確認できる座標一覧。
- `spec/asset_manifest.json`：素材名・寸法・透過情報・ハッシュ。
- `spec/layout_spec.md`：配置・拡縮・セーフエリアの仕様。
- `spec/codex_instructions.md`：実装担当への指示。
- `qa/`：元画像、再構成、差分4倍、50％重ね合わせ、透過素材の一覧、検証結果。
- `tools/`：素材抽出・比較に使用した作業スクリプト。実行には提供画像とPython環境が必要です。

## 確認してほしい点

枠・ボタン・アイコンの印象と、文字の雰囲気を確認してください。文字は変更可能なままにしているため、元画像のすべての字形と完全一致してはいません。Readyは元画像の5文字を輪郭化したフォントを使用しています。

詳しい相違点と測定結果は `qa/quality_report.md` に記載しています。この段階では5画面分の完成キットとは扱わず、ホーム画面の採用確認用として扱ってください。
