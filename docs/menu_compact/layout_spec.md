幅240px、高さ146px、角丸4px、外枠1px rgba(127,114,166,.745)。背景rgba(24,13,56,.922)。グラデーション/発光/影なし。通常色#f1eef8、未実装色#9690a8。区切り線rgba(160,149,188,.255)。文字は既存Noto Sans JP系400相当18px、line-height24px。既存フォントを継承し新しいWebフォントをダウンロードしない。

3主要アイコンはviewBox24×24、表示20×20、線幅1.4。矢印は同じ線幅のviewBox8×12。単色線画、fillなし、currentColor。SVGの描画方法により承認PNGのラスタ線と小さなアンチエイリアス差が生じ得るが、サイズ/色調/形は統一する。

## 実画面での位置

既存MenuボタンのDOM矩形を取得し、右端=Menu右端、上端=Menu下端+約11pxを基本にする。基準画像のMenu右端は約1448、下端は約59。既存Menuボタンを動かさない。文書/viewport座標を混在させない。fixed配置ならviewport座標を使う。

**240pxは実機でもCSS pxの幅を維持するポップオーバーの基準。** 1536pxのTOPキャンバスと一緒にtransform縮小して文字やタップ領域を縮めない。背景やTOP自体は既存の表示方法を保つ。Menuが変形コンテナ内にある場合はTOPのoverlay layerかbodyの専用portalへ載せる。既存TOPに影響しない名前空間のみで実装。

左右のsafe-areaと画面端8pxの内側へclamp。幅=min(240px,安全領域幅−16px)。通常iPhone横画面では240pxを維持、行高46CSSpxで44pxタップ基準を満たす。画面高さが不足したときは下部ナビ上端−8pxを上限としてパネルmax-heightを制限、内部だけ縦スクロール。幅不足時もアイコンや文字を重ねない。小さい文字へ勝手に縮めるより利用可能な領域を確認する。
回転/リサイズ/表示領域変更時は再配置。閉じている間は測定ループを走らせない。元画像は位置の参照であり、背景写真にメニューを焼き込まない。
