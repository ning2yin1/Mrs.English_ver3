# Codex向け実装指示書

## 目的と範囲

承認済みの小型2Dメニューを既存TOPの右上Menu直下に追加する。SVG4点とCSSを使う。以前の大型/光沢/3D版は採用しない。幅240px・高さ146px、3行のみ。今後実装予定の説明文も追加しない。

TOP写真/上部ステータス/Menuボタンの見た目・位置/下部ナビは一切変更しない。画面全体を別画面に切替えない。背景22枚/既存素材を変更・再生成しない。保存処理、カード/通貨/配布処理へ触れない。このキットは素材/スキン/仕様でありアプリの本体コードは含まない。

## 調査

Workではリポジトリを調査していない。既存TOPのDOM/CSS/変形コンテナ/Menuイベント、overlay layer、safe-area、ルーター、設定/遊び方の有無、既存フォント、PWAキャッシュを確認。実パスやURLを推測して新しい画面を作らない。

## 手順

1. references/menu_compact/approved_menu.jpegとlayout_spec.mdを確認。
2. assets/menu_compactの4SVGを使う。currentColorを継承させるには**inline SVG**として読み込む。外部img srcのSVG内部には親のcolorが継承されない。imgで使用する場合はCSS mask等を用いて色を適用するが、inlineを優先。全4ファイルに外部参照/スクリプトなし。
3. styles/menu_compact/menu.cssを専用名前空間で利用。既存button等へグローバルCSSを書かない。背景はCSS、文字はHTML、アイコンはSVG、TOP全画面PNGをクリック背景にしない。
4. 既存Menuをアンカーにして幅240CSSpxのパネルを配置。left/top用CSS変数を既存構成に合わせて設定。safe-areaへclamp。TOPキャンバスと一緒に縮小しない。
5. 3行はログインボーナス/設定/遊び方。ログインは少し暗い、選択時は閉じるだけ。設定/遊び方は既存ルートが存在すれば接続、存在しなければ未接続の安全なコールバックとして残し報告。
6. 再Menu/外側/行選択/Escapeで閉じる。外側タップの背後誤操作を防ぐ。180msの控えめな開閉、reduced-motion対応。
7. 実機と既存TOPの回帰を確認し、変更ファイル/接続先/未実装点を報告。

## 読込み速度

SVG4点は小さな静的ファイル。新規画像生成PNG、写真の複製、外部CDN、アイコンライブラリ、JSフレームワーク、Webフォントは追加しない。既存バンドラーでinlineするか既存ロード方式を利用し、初回に重い画像を取得しない。CSSは小さく1本。ポインターの常時計測ループ不要。既存キャッシュ更新は必要な最小範囲で行い、保存データやキャッシュ全消去はしない。
