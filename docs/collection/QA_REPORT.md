一覧と詳細はこのPillow再構成条件で全画素一致。空状態の差もごく少数画素の微小差に限定されます。`comparison.json` に詳細数値と元画像SHA、`*_difference_x4.png` に差分を4倍に強調した画像を収録。差分が真っ黒な画面は一致です。

目視でも3画面の位置、カード比率、人物、枠の光沢、一覧の下段クリップ、透明パネル、情報文字の重なりを確認。全PNG/JPEGデコード、6装飾PNGの透過、写真79枚/枠5枚/承認背景の原本byte一致、既存共通10ファイルのGit blob一致、既存パスとの衝突0を検証しました。機械検証はasset_validation.jsonに収録。

発光画像は透明余白を含めて書き出し、余白ごと指定座標に配置。detail_auraの下端は承認画像由来の低濃度光がキャンバス上でなじむ仕様で、追加のoverflowクリップやtight cropを行わないでください。ガラス罫線の1pxも除去しないでください。

本結果は画像合成QAであり、ブラウザ・iPhone・保存・操作の実装テストは行っていません。DOM文字の描画とPillowにはアンチエイリアス差が出る可能性があります。実装時に指定フォント・インク上端の補正を守り、同条件のスクリーンショット比較を追加してください。

再現手順（既存依存素材が存在するリポジトリルートへ展開した後）:

```sh
python -m pip install -r qa/collection/requirements.txt
python qa/collection/reconstruct.py --root . --out /tmp/mrs-collection-qa
```

このツールは画像QAのみで、ゲームやlocalStorageを操作しません。
