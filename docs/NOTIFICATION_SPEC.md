# 全画面共通ミッション達成通知

## 配置・構造

正本は`references/mission_notification_approved.jpeg`。1536×710でx=368,y=73,w=800,h=46、TOPヘッダー下端59から14の間隔。濃紫rgba(24,14,54,.898)、青紫1px枠、上辺だけ薄い光沢、角丸5。背景を暗くする全画面幕は作らない。

構成順：チェックSVG、ミッション達成！、縦線、ミッション名、縦線、通貨アイコン、＋数量。Rコインは例「＋300 R」、ダイヤはダイヤアイコン＋「＋5」。ラベルと数量はHTML。通知は高さを維持し、名前領域だけ縮小・省略可能。全文は同じaria-live文に保持。折返しで大きなパネルに変えない。

`styles/mission.css`の`.me-mission-toast`をアプリ共通シェルに一度だけ置く。現在画面のヘッダーの実際のCSS座標下端を`--header-bottom`に設定。TOPの59pxを他画面へ固定流用しない。セーフエリアを含んだ下端なら二重加算しない。縦横回転・ウィンドウ変更・ヘッダー高さ変更時に再測定。ノッチを避けた安全領域の中央にクランプし、横幅は安全領域幅以下にする。安全領域が左右非対称ならleft位置も補正する。

z-indexは既存レイヤー体系へ合わせる。ゲームHUDより上、重要なエラー/確認ダイアログより下を基本にする。通知要素とそのラッパーすべてpointer-events:none。スクリーン全体を覆うクリック捕捉要素やフォーカス移動は不要。`role="status" aria-live="polite" aria-atomic="true"`。操作ボタン・閉じるボタン・効果音なし。

## 時間とキュー

|相対時刻|状態|表示|
|---|---|---|
|0〜180ms|enter|上6pxから所定位置へ、opacity 0→1|
|180〜3,180ms|hold|約3秒間保持|
|3,180〜3,400ms|exit|opacity 1→0、位置は維持|
|3,400〜3,500ms|間隔|隠す。次の通知へ|

`data-phase`をenter/hold/exit/hiddenに変更。タイマー/遷移完了の双方から同時に次へ進まないよう状態IDで一度だけ完了する。時間は調整可能な設定値として扱う。動きを減らす設定はスライド/フェードを省略し、同じ読める保持時間で表示する。

通知IDは報酬付与キーと対応し、同じIDはキューへ重複登録しない。複数達成をまとめて重ねず順次表示。ルート変更でも同じ共通シェルとキューを維持し、タイマーを重複起動しない。背景へ移った間は表示を停止し、復帰後は残りの保持時間を使う。画面遷移で表示済みの報酬を再付与しない。

## 再起動・保存失敗

報酬が確定保存された後だけ表示。未表示outboxは次回起動時に順次表示可能。ただし表示開始前に通知を「表示開始済み」として保存し、再起動では既に開始済みの通知を再表示しない方式を推奨。これにより開始直前の強制終了では通知だけが省略される可能性があるが、報酬は失われず、二重表示/二重付与を避けられる。クラッシュをまたいで通知の厳密な一度限り表示と完全な表示保証は両立しないため、報酬の一度限り確定を最優先にする。

日付更新で未表示の確定済み報酬を取り消さない。古いoutboxを扱う際も新期間の達成として再加算しない。通知のonEnter/onExit/再表示は残高変更を行わない。
