# Codex実装後の確認項目

以下は実装後テストであり、このキット制作でアプリ動作を検証済みという意味ではありません。

## 見た目

- [ ] 1536×710で日次/週次を参照JPEGと比較。6行、名前/条件/報酬/状態の順・金枠を維持。
- [ ] 844×390、852×393、740未満横幅で文字・数値が重ならず、必要時は一覧だけスクロール。
- [ ] ノッチ左右・セーフエリア・PWA/ブラウザ高さ変化・復帰時に画面外へはみ出さない。
- [ ] 日次/週次タブが青/紫で切替。未着手・進行中・達成済みは文字でも区別。
- [ ] 0%、1/15、100%、目標超過時のゲージが枠から出ない。
- [ ] コインとダイヤの違い、1,000等の桁区切り、5/20の特別報酬が正しい。
- [ ] 文字・数値が画像に焼き込まれず、受け取りボタンが無い。

## 判定

- [ ] D01=10問完了、途中終了はクリアに含まない。0正解でも10問完了ならクリア。
- [ ] D02=正解15回。誤答、再描画、同じ採点の再送で増えない。
- [ ] D03=実連続5正解。誤答で切断、ステージ間で足さない。コンボ保護後の見かけの5だけでは不可。
- [ ] D04=異なる文法2、W03=10。難易度違いの同一文法は1種類。
- [ ] D05=NORMAL/HARD、W02=HARDだけ3回。EASYを含めない。
- [ ] W01=15ステージ、W04=10/10の完了ステージ3回。
- [ ] W05=強化成功3回。上限/不足/キャンセル/保存失敗は0回。
- [ ] 先行5件でD06/W06が一度だけ達成。6行目自身をn/5へ数えない。
- [ ] 1回のプレイで複数の両期間ミッションが正しく更新。
- [ ] 途中終了後も既に確定済みD02/D03進捗・ミッション報酬は維持、ステージ報酬は既存規則。

## 更新・保存・通貨

- [ ] JST日曜23:59:59→月曜00:00:00で日次/週次を両更新。
- [ ] 通常の火曜00:00は日次だけ更新。端末TZが海外でもJSTを使用。
- [ ] 閉じたまま日/週/複数週をまたぎ次回起動で正しい期間。
- [ ] 日跨ぎの回答とステージ完了はそれぞれ確定時の期間へ。
- [ ] 同じイベント再送・リロード・タブ再訪・通知再生で二重報酬なし。
- [ ] 保存失敗/強制終了から復旧して残高・達成フラグ・カードに食い違いなし。
- [ ] 複数タブで同時操作しても最新残高を排他内で確認。
- [ ] 既存ユーザーのカード/レベル/テストカード/無料パックフラグ/残高を維持。
- [ ] ダイヤ9で交換不可、10でR+1,000/ダイヤ0、再送で重複消費なし。
- [ ] Rダイヤ4不可/5可、S2不可/3可、A/B/C追加消費0。コイン不足も不可。
- [ ] 強化費は既存値のまま。失敗で片方の通貨だけ減らない。
- [ ] 強化報酬の先借りで不足強化を許さない。

## 通知と既存機能

- [ ] TOP/学習/Shop/Inventoryでヘッダー下に表示、写真・操作を隠しすぎない。
- [ ] 全領域pointer-events:none、操作継続、フォーカス移動なし。
- [ ] 複数同時達成は順序通り1件ずつ。ルート切替で二重生成・二重表示なし。
- [ ] 長い名前は通知幅内に収まり、報酬数量は残る。ダイヤ通知も確認。
- [ ] 約3秒保持＋短い出入り。動きを減らす設定でスライドを省略。
- [ ] バックグラウンド復帰で通知タイマーが多重化しない。
- [ ] 通知が省略/中断されても報酬は確定済みで失われない。
- [ ] TOP/Menu/Collection/Inventory/Shop/通常ガチャ/READY/プレイ/リザルトに退行なし。
- [ ] 背景写真22枚・人物写真・カードを再生成/再出力/強制先読みしていない。
- [ ] 初回ロードに参照JPEGや未使用資産を含めず、Mission用CSS/背景は必要時に読む。
