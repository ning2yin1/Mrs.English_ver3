# Mrs. English Ver.3 — 第1段階

既存アプリとは独立した、iPhone横画面向け静的PWAです。納品された画像・JSON・フォントは変更せず参照しています。

## 起動

Node.js 24で確認済みです。ランタイムに外部サービスやAPIキーは必要ありません。

```sh
cd /workspace/Mrs.English_ver3
npm ci
npm run build
npm run preview
```

HTTPサーバーは4173番ポートで起動します。制作中は `npm run dev` でも起動できます。オフライン動作の検証は `build` 後の `preview` を使用してください。

`dist/` をHTTPSの静的ホスティングへ配置できます。全パスは相対参照のためサブディレクトリ配信にも対応します。iPhoneのSafariで開き「ホーム画面に追加」で起動してください。PWAインストール・サービスワーカーにはHTTPS（ローカル検証時はlocalhost）が必要です。iOSの向きロックは保証されないため、縦向き時は横向き案内を表示します。

## 構成

- `src/app.js`: 画面遷移と表示領域への均一拡縮。
- `src/screens.js`: 画面別の動的な写真・選択状態・入力・タップ領域。
- `src/components.js`: 納品画像・独立SVG文字・ボタン・9-slice。
- `src/profile.js`: 保存データの検証とlocalStorage例外処理。
- `public/backgrounds/`: 提供ZIPの元画像。`layouts/external_backgrounds.json` の対応を維持。
- `public/sw.js`: オフラインキャッシュ。ビルド時に素材とコードからキャッシュ版を生成。
- `qa/browser/`: 実際のブラウザーキャプチャ、モックアップとの比較、機能検証結果。

初回はタイトル→ニックネーム→推し→背景→ホーム。2回目以降もタイトルを表示し、タップ後はホームへ進みます。保存キーは `mrsEnglishV3.profile`。学習・ガチャ・カード・課金は実装していません。各ホームボタンの遷移先は空白画面とホームへ戻るボタンのみです。

## 検証

起動したpreviewサーバーに対して実行します。

```sh
npm test
python3 scripts/compare.py
```

ブラウザーテストはPlaywrightと `/usr/bin/chromium` を使用します。別環境では `CHROMIUM_PATH` と必要なら `TEST_URL` を指定してください。画像比較だけはPythonのPillowが必要です。

比較ページは開発サーバー上の `qa/browser/index.html` にあります。制作キットのモックアップやQA画像は本番ビルドへ収録していません。

## 残る確認事項

- iPhone実機のSafari、ノッチのセーフエリア、ソフトキーボード、PWAインストールは未検証です。844×390と縮小表示領域はChromiumで確認しています。
- 背景選択・ホームの写真は、モックアップの生成済み比較用写真ではなく、提供された22枚の元写真を使用しています。特にbg-01は構図が異なり、元写真の文字や人物位置も異なります。画像を改変・生成せず、中央coverで表示しています。
- 選択を他の推しへ移した状態は新たな承認モックアップがなく、納品フレームを9-sliceで適用しています。納品の写真レイヤー・人物切り抜きに、元の選択枠の淡いシアンの光が一部残っており、未選択の大森元貴カード付近に小さく見える場合があります。
- 固定文字には納品の限定フォントを使用しています。任意のニックネームと変更後のプレビュー番号はフォールバックで表示します。未フォーカス入力欄に見本の固定カーソルは重ねません。
- 公開先へのデプロイおよびiPhone実機検証は未実施です。
