`mission_definitions.json`は以下の定義データです。文字列、目標、報酬を変更しないでください。`r_coin`/`diamond`は説明用の通貨種別であり、既存の残高キーへマッピングします。

達成条件のデータ正本はこの表です。承認済み画像の6行目には省略表示「上記5件をすべて達成」があります。UIでも同義の省略表示として使用可能ですが、定義や判定対象は必ずD01〜D05 / W01〜W05です。

## 画面状態

- `untouched`：進捗0、未着手、ゲージ0%。
- `in_progress`：0より大きく目標未満、進行中。
- `completed`：達成・報酬コミット済み、達成済み、チェック、青ハイライト。
- ゲージは`min(max(value / target, 0), 1) × 100%`。表示数も目標で上限を設ける。内部集計の必要な実績は失わない。
- ヘッダーの「達成状況 n / 5」は先行5件のみ。6行目自身は数えない。
- 6行目の進捗は先行5件の達成数。報酬はD06=5ダイヤ/W06=20ダイヤ。
- 報酬値は正の整数、3桁区切り。Rコインの円形Rとダイヤの菱形を混同しない。
