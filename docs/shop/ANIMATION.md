# 開封演出仕様（実装は今回行わない）

調整値はdata/shop/animation.json。静止画素材をCSSのtransform/opacityとJavaScriptの状態遷移で制御する。動画は不要。タイミングは初期案で、後から変えても購入・抽選・所有データへ影響しない。

|状態|初期時間|動き/遷移|
|---|---:|---|
|PACK_READY|待機|パック中央。1800ms周期の弱い発光。タップ待ち|
|PACK_SHAKE|220ms|x±7px/回転±2度、最後に原位置|
|GLOW_BUILD|220ms|ハローを1.0→1.35倍、opacity増加|
|SEAL_OPEN|280ms|同じパックPNGを2レイヤーで表示し、上端9.5%と下部をclip。上端を34px上へ/−5度/フェード。下部を1.03倍して消す|
|BACK_ENTER|220ms|既存裏面を下18px→原位置、opacity0→1、scale.94→1|
|BACK_READY|待機|案内と進行ドット。タップで現在indexをめくる|
|FLIP|520ms|card wrapperをrotateY(0→180deg)。perspective約1100px|
|REVEAL_FX|220ms+ランク別hold|固定の当選表面へ切替、ランク別ハロー・粒子・単発flash|
|FRONT_READY|待機|次へを有効化。最後は「結果を見る」|
|NEXT|160ms|現在カードをフェードしindex+1の裏面へ|
|RESULTS|220ms|同じレシート全件を表示。OK/Inventoryへ|

パックを切り開いた新しい絵は作らず、承認済みパック原本を二重表示してclipし、光の強い瞬間に裏面へ移る「開いたように見える」演出とする。クリップは表示だけで、元PNGを加工・再生成しない。枚数バッジと数値は下部wrapperへまとめて追従させ、封切り上部に重複させない。パック種によって印刷位置が違う場合はsealClipFractionだけ調整できる。

## カードの回転

表裏の2面を同寸・同位置で重ね、裏面はrotateY(0)、表面はrotateY(180deg)。wrapperを0→180deg回すと、前半に裏面、90度以降に表面が見える。両面backface-visibility:hidden（必要に応じ-webkit版も指定）、wrapperにtransform-style:preserve-3d。回転中に画像ファイルを読み込み直さず、事前decodeした確定表面を使う。写真/枠を別々に回さず同じcard groupへ入れる。裏面と枠の比率は1060:1484で共通。承認静止画では裏面350×490、R表面388×543なので、flip groupの基準を388×543、開始scale=350/388・中心(922,421)、終了scale=1・中心(922,416.5)として同時補間し、表面が突然大きく飛び出す切替にしない。

iPhone Safariでの実機検証は未実施。CSS3Dが使用できない/描画が崩れる環境では、確定済み表裏のopacityクロスフェードへフォールバックし、抽選や付与を再実行しない。

## ランク差

Cは控えめな白、Bは赤、Aは紫、Sは強い紫+金の内光と少量の星、Rは承認画像の豪華な金色放射/2重ハロー/金粒子/単発フラッシュ。Rの強さを基準1として他ランクを抑える。profileのpeakOpacity/particles/flashOpacity/revealHoldMsを設定で変更できる。フラッシュは1回だけで連続点滅にしない。

粒子は同一の透明星スプライトを複数配置し、パック/カードの後ろから緩く外へ広げる。Rは20個前後、S10、A4、B2、C0を初期値とする。写真の上へ色フィルターをかけない。動画や大きいフレーム列は使わない。端末負荷を見て粒子数・回転を減らせるようにする。

## スキップ・中断

スキップは購入/抽選/付与のAPIではなく、演出だけを終える操作。承認済み静止画③の待機中と⑤の公開完了時へ新しいボタンを足さず、演出中の操作レイヤーで④の既存スキップを同位置/同素材で再利用する。開封/めくり/レア演出中も同じ位置のスキップ操作を利用可能にし、現在のタイマー/transitionend listener/particle loopをキャンセル、世代tokenを更新して古いcallbackを無効化し、同じreceiptIdの結果一覧へ移る。めくるたびに抽選・付与しない。

演出完了待ちを保存処理の条件にしない。購入commit・付与の永続化後に初めて演出を開始する。アプリを閉じた/バックグラウンドになった場合、永続レシートから再開できる。表示進捗の保存が無い/不正なら結果一覧を安全な既定復帰先とし、すでに買った物をもう一度課金・付与しない。

prefers-reduced-motionでは揺れ/回転/粒子ループ/flashを止め、140ms程度のopacity遷移にする。visibility復帰時は状態を確認し、残ったアニメーションcallbackから次の購入が発火しないようにする。演出テストはCHECKLIST参照。
