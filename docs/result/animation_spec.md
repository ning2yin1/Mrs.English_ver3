## スキップ

演出中は画面タップで即座に通常リザルトへ。途中の見かけの点数で確定せず、既に計算済みの最終値・内訳・評価・報酬を表示する。アニメーションは表示だけで、スコア/コインの付与を行わない。スキップ、連打、画面再表示で重複付与しない。スキップした最初のタップを、その直後に現れる「もう一回」等の操作へ通さない。

音は将来の同期イベントを記載しただけで、今回制作しない。カウント音は毎フレーム鳴らさず最大20〜30回/秒。スキップ時はカウント音を停止し、確定音を重複再生しない。

## 調整と配慮

各時間・カウント速度・粒子量・発光強度は独立パラメータにする。フル画面連続点滅や大きな画面揺れは使わない。写真にフィルター加工を焼き込まない。prefers-reduced-motionでは残像/拡大/衝撃波を止め、短いフェードで確定表示へ。バックグラウンド復帰で演出が止まった場合も通常画面へ移行できるよう、animationendだけに依存しない。


## Codex向けの再現方法

全体は単一の結果表示コントローラーで「演出中→通常表示→遷移中」の状態を持つ。requestAnimationFrameとperformance.nowの相対経過時間を唯一の演出時計にする。複数setTimeoutやanimationendの鎖を進行の唯一条件にしない。タイムライン各区間は配列設定に分離し、時間/強度/粒子数/scaleを後から調整可能にする。

各加算区間で、start=直前項目までの表示整数の累計、end=start+当該項目の表示整数。u=clamp((elapsed-startTime)/duration,0,1)、easing=1−(1−u)^3、表示=floor(start+(end−start)×easing)。区間終了で必ずendを代入。0点区間は加算せず待機して次へ。最終値は確定済みtotalScoreへ必ず一致させる。raw採点をこのループで再計算しない。

スコア数字はHTMLテキスト、tabular-nums、一定の表示幅、3桁区切り。残像は同じ現在文字列をaria-hiddenの複製レイヤーに置き、上下translateY±8px、opacity .15以下、blur2〜4px。確定時はscale1→1.12→1、transform-origin:center。文字サイズのレイアウト変更で周囲を押さない。

カード発光はカード画像と別の外周レイヤー。スキル区間は実際に発動したカードだけ、デッキ区間は開始時3枚全体。haloとshockwaveは画像/SVGを重ね、transform/opacityだけで動かす。particle SVGは一枚の軽量レイヤーとしてopacityとscaleを動かす。より個別に動かす場合もDOM粒子は最大70、ランダムseedをstageIdに固定し再描画のたびに配置を変えない。

評価PNGは正解数から1種類選び、contain、縦横比固定、opacity0→1/scale.85→1.05→1。余白を含む推奨boxを使い発光を切らない。PERFECT以外の素材は今回同じシリーズとして追加、承認済みPERFECTは原画像を無変更再利用。

中央から通常画面への収束は、スコア表示を複製しFLIP方式等で「中心768/y322、137px」から「中心405/y299、94px」へ補間。元/先の両数字を同時に見せない。右パネルと内訳はopacityを遅らせる。各最終座標はdesign_specを参照。

## 音とイベント

result_enter / count_start / skill_trigger / score_impact / rank_reveal / reward_revealは同じ時間軸のイベントIDとして一度だけ発行。visualとoptional audioが同じイベントを購読。効果音が未登録・ロード失敗・Safariのユーザー操作制限でも進行を止めない。
将来のカウント音はWeb Audio APIの短いoscillator+gain envelopeで生成可能。1000回加算しても1000音鳴らさず、固定間隔（約33〜50ms）に間引く。今回音源/再生コードは制作しない。背景化でAudioContextが中断しても復帰時に過去の音を一斉再生しない。skipは予定音/ループを破棄、通常画面を無音で確定表示し、確定音を重複させない。

## 操作・中断

pointerupでスキップ判定し、skipを冪等にする。直ちに全演出/RAF/予定音を取り消し、通常表示を完成値で描画する。その同じpointerupから現れたボタンを押せないよう、イベント伝播遮断とスキップジェスチャーIDの消費を行う。次の独立したpointerdown/upからボタン操作を許可。固定時間だけのdebounceに頼らない。
操作領域はtouch-action:manipulation。viewportでuser-scalable=noにして利用者の拡大操作を全面禁止しない。ボタン/演出タップのダブルタップ拡大を抑えつつ、アクセシビリティのズームは維持。
reduced-motionは通常表示へ即移行または150msのフェードのみ。非表示時は停止し、復帰時は通常表示へ。確定データや報酬はどちらでも変わらない。画面破棄時はイベント/RAF/audio購読を解除。
