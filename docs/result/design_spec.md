# デザイン仕様

基準1536×710、横画面。写真は直前ステージのbackgroundId/object-positionを維持しcover。黒濃紺rgba(3,5,24,.60)を独立レイヤーで重ねる。背景写真へ暗さ・色・ぼかしを焼き込まない。

光沢バー・パネル・青/紫ボタンは既存PNGを利用。9-sliceはreuse_bindings.jsonを参照（上右下左）。HTML buttonのラベルは独立文字。背景・カード・数値の焼込なし。評価のみ固定ラベルの特殊装飾PNGを例外とする。実際の評価で5種類を切替え、別途DOMの評価テキストを読み上げ可能にする。

色：白#f6f5ff、補足#c2cce8、シアン#66e6ff、金#ffe7a1。字体は既存Noto Sans JPとNimbus Sans系を再利用。PNGの切抜きで文字・数値を作らない。

## 演出画面

中央パネル180/120/1176/463。STAGE CLEAR中心768/y146/28px。カウント数字中心768/y294/133px、確定中心768/y322/137px。カウント説明中心768/y467/26px、進行線385/521〜1151/521。項目名はx430から170pxピッチ/y552/18px。演出評価430/171/676/149にcontain。確定TOTAL SCORE中心768/y481/23px、正解数/率中心768/y533/25px。カード110/590から81pxピッチ、61×85px。スキップ案内右端1424/y650/19px。

SVG光輪はスコアを囲む1024×512領域を基準にし、独立回転/拡大/フェード可能。粒子が数字・ラベルに被る場合は文字より下に置く。背景の写真は移動しない。

## 小さいiPhone

安全領域はenv(safe-area-inset-*)内、写真のみ全画面。基準座標は安全領域に中央寄せcontainする照合用。実機ではタップ44CSSpx以上、内訳文字14CSSpx程度・補足12CSSpx以上を目安にする。一律縮小で10px以下にしない。短い横画面はヘッダーと下部3ボタンを固定し、左右パネルの本文を内部スクロールへ。スコア・評価・正解数は固定で優先。項目名省略やスコアの横圧縮は禁止。長い文法名は短縮表示+アクセス可能な正式名、長い数値はスコア文字だけ段階的縮小。縦画面は回転案内。今回実機UIは未実装。
