# 制作キット品質確認

- 承認済み3画像と元2文書を無変更コピー。元ZIPに含まれていた一時ファイルは再収録していない。
- 承認時と同じ素材/配置による3画面の静止画再構成はRGB比較で平均絶対差0、最大差0。reconstruction_metrics.json参照。これは静止画合成の照合であり未実装ブラウザの描画保証ではない。
- 評価5種のPNGをデコード、全評価画像のアルファ最小0/最大253〜254を確認（文字面はほぼ不透明、発光部は半透明）。5種の文字と色を目視確認。写真/点数/カードは焼き込まれていない。
- 独立FXはSVGの透過背景、viewBox・XML構造を検査。外部参照/スクリプトなし。光輪・粒子はDOM文字と分離して動かせる。
- 既存共通PNGは再生成せずコピーし、ハッシュを記録。
- サンプル5内訳合計24527、450×2=900、表示端数配分例合計1614を確認。
- 5評価の境界、二重加算防止、スキップ、遷移、セーフエリア、保存互換性の仕様を文書化。
- ZIPは英数字パス、余分な親フォルダ・一時ファイル・アプリ本体コードなし。

未実施：Safari実機の表示/タップ/音、既存採点/保存/報酬処理のコード監査、スキップや二重付与の動作テスト。今回は素材/仕様のみのため、これらはCodex実装時の必須確認。安全性の仕様を書いたことを実装済みと見なさない。
