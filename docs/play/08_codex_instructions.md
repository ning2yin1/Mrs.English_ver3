# Codexへの実装依頼文

Mrs. English Ver.3にREADYと英語プレイ機能を追加してください。このZIPは素材・仕様で、実装済み機能ではありません。

## 作業前に調査・報告

公開中のTOP・Collection・Inventory・Shop・ガチャのデザインと機能を維持。既存ディレクトリ、ルーター、保存version、装備3枚/総合力/スキルの関数、Rコイン精算、共通UI画像、PWAキャッシュを確認。既存カード/レベル/初回入手日/無料パック受領/開発配布履歴は保持。このキット内にリポジトリ調査済みの主張はない。

`00_findings.md`を読み、既存実装のスキル率が+5%/+20%と違う場合は差分を報告。独断でカード値を書き換えない。実パス不明の共通素材はexisting_asset_bindings.jsonの過去キット名/ハッシュを手がかりに発見する。

## 追加の順序

1. 既存データをバックアップ可能にし、追加前後で互換性を確認。保存の全消去・新規の重複コインストアは禁止。
2. データ原本grammar_01_40.jsonを読み取り専用で取り込む。40文法400問を動的表示。検証レポートの候補を無断適用しない。
3. 既存TOPのREADYボタンに既存の遷移方式で接続。READY2状態をreferenceと比較。
4. 開始時10問を重複なしランダム抽出、背景22枚から1枚固定、装備snapshotを取得。
5. EASY4択、NORMAL/HARDの独立タイル・取消・採点・NEXT。4択に増えた以外は装飾/レイアウトの雰囲気を保つ。
6. 正解/残念、正しい英文・和訳・原文解説、スキル表示。一時停止・終了確認。中断と計時の保存復元。
7. 採点式/カードボーナス/日次2倍を実装。scoring_examples.jsonで照合。
8. 10問完了時に一度だけ精算し、次工程向けStageResultを残す。新リザルトやミッションの本格デザインは実装範囲外。既存UIの仮完了表示で結果確認を可能にする。
9. 既存画面の回帰確認、実機landscape/safe-area、タップ44CSSpx、最大14タイル・長文・4択を確認。

画像素材を優先して紫バー・光沢ボタン・装飾パネルを再利用。CSSは主に配置、文字、選択状態、発光、操作、スクロール。全画面1枚のPNG＋透明ボタンは禁止。写真を再生成/加工しない。データ追加で文法/例文一覧が自動更新される構造にする。

## 完了時に報告するもの

追加/更新ファイル、既存処理との接続点、保存互換性、スキル差分の扱い、未校正の問題候補、確認端末とテスト結果。まだ調べていないものを実装済みと報告しない。

このWork制作時点ではアプリ実装・GitHubアクセス/変更・デプロイは一切行っていない。
