## 一時停止・途中終了

プレイをそのまま保持し、追加の暗幕0.45、既存パネル487,215,870,430。パネル内だけ暗紫の下地を約96%で重ね、背後の問題文が透けて重複しないようにする。外周の写真は見えるまま。見出し「一時停止」、再開ボタン622,365,600,80、途中終了ボタン622,475,600,80。
終了確認も同枠で「ステージを終了しますか？」「スコアとRコインは獲得できません」。左/右ボタン「戻る」「終了する」。元背景は保持。モーダル外タップで採点/終了しない。

## セーフエリアと実機のタップ範囲

背景は画面全域。UIはenv(safe-area-inset-*)内に収める。基準UIキャンバスの拡大率s=min(安全領域幅/1844,安全領域高さ/853)、余りは中央寄せ。reference座標×s＋安全領域原点で配置。縦画面は回転案内・操作と計時を停止。
ただし単純縮小で67pxボタンを実機31pxにしない。タップ可能領域は44×44 CSS px以上。元画像の薄いボタンの光沢は維持し、独立hit areaを広げる。隣のhit areaが重なる場合はコンパクト配置へ切替。
コンパクト配置は上部HUDと下部操作を固定し、中央に回答/単語バンクを収めてその部分だけスクロール。単語ボタンの行高44CSSpx以上、本文は最低16CSSpx、単語は最低16CSSpx、補足は最低12CSSpx。HARD最大14タイルの実データ、長いフレーズタイル、iPhone844×390と667×375で確認する。2×2 EASYも同様。読みやすさを犠牲にした一律縮小は禁止。基準画像との比較は1844×853、実機は安全領域とタップ性の両方で評価。
