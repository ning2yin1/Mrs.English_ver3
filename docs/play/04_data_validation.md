# 400問JSON 検証レポート

## 原本

入力は今回添付のmrs-english-400-retry(1).zip。ZIP内grammar_01_40.jsonを無変更収録。SHA-256はvalidation_summary.jsonとfile_manifest.csv。元のREADME・validation_report.txtもそのまま保存。本レポートが今回の追加検証であり、元検証文面を書き換えていない。

## 全件構造検査

40カテゴリ、400問、カテゴリごと10問、question_count=400と一致。カテゴリID・問題IDは一意。全問に英語/和訳/解説。EASYは全400問4択・重複候補なし・正解候補1件・空欄1箇所・正解挿入後の英文一致。NORMAL/HARDは全問answer_orderが全正解タイルの順列。HARDは全問2個のダミー、同一候補/正解タイルと完全同一の文字列重複なし。致命的な構造エラー0。

## 表示上の注意

11-10のT-shirtsはT / - / shirtsへ分割されている。単純空白結合だと元英文と異なるが、タイル列としては扱える。句読点の空白を除く比較でもこの1問（NORMAL/HARDの計2件）は別文字列になる。英文表示はenglishを使う。語句タイルを含む問題は40問、英文最長63文字(32-04)、HARDの最大タイル数は14個(30-08)。全問が単語単位とは限らない。

## 教材としての要確認

`question_review_candidates.csv/json`に114行の候補。27問に明らかに不自然な自動生成候補（例sing→s/ss/sed、I’m→I’ms/I’med/I’ming、on→ons/oned/oning）。これらは構造検査PASSでも教材としての校正が必要。綴りの典型的誤りを出すこと自体を禁止するのではなく、狙った文法と無関係な自動付加を問題視している。
その他、many/several、will/be going to、while/when、not to/to not等は同じ和訳でも複数の自然な英文が作れる可能性がある。冠詞/代名詞など「別候補も英文として成立するが訳が違う」ケースとは区別した。
No.04〜40は元READMEでも規則ベースの初稿と明記。カテゴリ共通解説は37カテゴリ、学年仮分類は20カテゴリ。CSVのカテゴリ-*行はカテゴリ全体の注記で、具体的な問題エラー件数と合算しない。

## 修正の取り扱い

原文は一切変更していない。CSVは修正候補であり、自動適用パッチではない。Codexも独断で正解やダミーを生成し直さない。原本を利用した動作実装は可能だが、公開教材としての自然さ・一意性は校正未完了として報告する。全400問の完全な意味校正・人物の事実確認を完了したという保証ではない。今回実施したのは全件構造検査、既知の不自然語形の全件検索、英語と選択肢の重点レビュー。

HARDは文法的に別の英文が作れる場合もある。和訳に一致する原文タイル順を正解として扱う現在の仕様をUIに説明し、将来の別解追加はデータ別版と承認を要する。複数解を無条件に誤文と説明しない。
