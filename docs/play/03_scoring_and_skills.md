# 採点・スキル・Rコイン

## 正式な計算式

難易度の基本点B、最大速度点VはEASY(1000,500)、NORMAL(1500,750)、HARD(2000,1000)。
回答時間t秒は操作可能な問題表示完了から決定までの実プレイ時間。0未満を0扱い、30秒以上でも回答可。

速度点 = V × max(0, 1 − t/30)
正解問題点 = B × (1 + 装備SCORE UP増加率の合計) + 速度点 × (1 + 装備SPEED UP増加率の合計) + min(正解後コンボ,10) × 50
不正解問題点 = 0
カードボーナス = 開始時デッキ総合力P × 正解数c × 0.01
最終スコア = round_half_up(10問の問題点合計 + カードボーナス)

端数は各問題・各ボーナスで丸めない。最終合計でのみ四捨五入（非負値の0.5は切上げ）。JSの小数誤差対策は有理数/固定小数等で行い、表示の整数を次の計算入力に使わない。回答時ヘッダは累計の切捨て整数を仮表示し、最終のみ確定値。速度は整数ミリ秒で保存し、秒表示への丸めを計算に戻さない。
カードボーナスにはスコアUP・速度UP・日次2倍を掛けない。コンボ点にもスコアUPを掛けない。

## コンボ

初期0。正解で+1、最大10。不正解で0。ただしCOMBO SUPPORT残数があれば1消費し直前値を維持。その誤答でコンボ加点は得ない。支援で守った次の正解は維持値+1から再開。

## スキル

暫定SCORE UPは1枚ごと+0.05、SPEED UPは1枚ごと+0.20。2枚なら+10%/+40%、乗算積算はしない。COMBO SUPPORTは1枚ごと1回分、2枚なら2回。全種類とも開始時装備スナップショットから求める。

既存カードにlevel別効果値やskill.kindがあれば、まず既存の読み取り/計算関数で値を取得。Inventoryの画像だけを根拠に+8%を実装済みと断定しない。実装値が暫定仕様と違う場合、カード値を勝手に書き換えず差分を報告する。共通の効果計算を一箇所に集約し、UIと採点が同じ解決済み値を使う。未知スキルは勝手に別名へ割り当てず要確認扱い。装備なし・3枚未満の場合は既存ルールを調べ、暫定では空枠0能力/スキルなしで開始可能（ゲーム内の配布や装備は行わない）。

## 報酬

10問完了に対してEASY300、NORMAL450、HARD600 Rコイン。毎日最初の5完了ステージは2倍、各600/900/1200。正解数による倍率はない。スコアUPや速度UPも報酬コインに影響しない。
日次境界は暫定Asia/Tokyo 00:00。完了トランザクション時の当日完了数が0〜4なら2倍、5以上は等倍。その後1増やす。途中終了は加算しない。既存に別タイムゾーン仕様があれば先に差分報告。

## 計算例

総合力6270、10問全正解、全回答0秒、スキルなし：
コンボ点=50×(1+…+10)=2750。カード点=627。
EASY=10000+5000+2750+627=18377。
NORMAL=15000+7500+2750+627=25877。
HARD=20000+10000+2750+627=33377。
EASYで全回答30秒なら13377。0問正解ならスコア0、ただし10問完了のコインは300（最初の5回なら600）。
EASY全正解0秒、SCORE UP1枚なら基本点合計10500、最終18877。
小数例：P=6271、EASY1問正解、t=10.001秒、残り9問誤答、スキルなし → 基本1000+速度333.316666…+コンボ50+カード62.71=1446.026666… → 最終1446。
この値と境界条件を `specs/play/scoring_examples.json` に収録。モックアップに印字された+1200は採点期待値に使用しない。
