# レポジトリへの追加手順・対象一覧

このキットをルートへ展開。assets/play・data/play・specs/play・styles/play・docs/play・references/play・previews/playは全て追加用。README_PLAY_KIT.mdとfile_manifest.csvも追加。既に同名があるときは先に差分を確認し、そのまま上書きしない。

今回更新/上書きした既存ファイルは0件。新旧キットの共通素材やコードの再収録は原則行わない。過去キットの実際の画像は既存レポジトリから再利用する。写真22枚は依頼に従いplay/backgroundsへ原本を再収録している。

## 実装時に変更が必要になる可能性のある箇所

実ファイル名は未調査のため推測で作らない。以下はCodexが確認して最小変更する接続箇所。
- TOPのREADYボタン：既存導線を新しいREADYへ接続するイベント/ルートのみ。外観変更なし。
- 既存ルーター：READYとplayのルート追加。
- 既存保存モデル：stage session/result、精算済みstageId、日次完了数、文法×難易度の記録を追加。未知フィールドを保持。
- 既存Rコイン更新：既存の安全な更新処理へステージ精算を接続。
- カード/スキル計算：既存関数を読む。矛盾があれば差分報告し、データ値は独断更新しない。
- PWAキャッシュ：新しいデータ/装飾の適切なキャッシュ登録。既存キャッシュや保存を全消去しない。

UI・状態処理はplay専用の名前空間へ。リザルト/ミッション本格画面・Shop抽選・新しいカード配布機能は作業対象に入れない。
