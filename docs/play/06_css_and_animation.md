# CSS再現と演出

`styles/play/play_reference.css`は実装のための参照断片。アプリや画面遷移は含まない。既存CSSへグローバルに貼らず、.me-play-kitの名前空間内に移植する。

## 画像に任せるもの

紫タイトルバー、青/紫の光沢ボタン、READY用の暗い装飾パネル、既存背景装飾、矢印は既存PNGを再利用。9-sliceの境界はexisting_asset_bindings.jsonの上右下左px。元PNGを背景として装飾だけに使用し、文字は別DOM。角を含む画像を横に引き伸ばすだけの処理は禁止。タイトルバーは1661×84の原比率を基準キャンバスで維持。
READYの本と正解ワードマークは承認時に使った透過原画像を収録。ワードマークは固定装飾としてaria-hiddenで使い、画面読み上げ用の「正解！」はDOMで付ける。自由な文字変更が必要な場合はCSSのテキスト表現へ。動的なスコア・訳・解説・スキル量は一切焼き込まない。

## CSSで制御するもの

黒65%フィルター、写真cover、文字/影、得点/コンボ、選択・使用済み・disabled、単語のflex-wrapとスクロール、細い光線、カード周囲のdrop-shadow、正誤カラー、pauseアイコン、モーダル暗幕。EASY4択は動的DOM。カード写真・フレームは既存描画部品のまま。

## 演出タイムライン（すべて後から調整可能）

|対象|時間|表現|
|---|---|---|
|ボタン押下|80ms|scale .98、離したら元へ。レイアウトを動かさない|
|タイル追加/取消|120ms|opacity/translateY 4px。連続タップを妨げない|
|正解|0〜280ms|青→金のhaloをopacity0→.65→.25、scale .96→1.04|
|不正解|0〜220ms|赤halo .35まで、本文全体を大きく揺らさない|
|スキル|0〜500ms|該当カード外周を発光、スキル名と実際の効果値を下部表示|
|次問|160ms|UIのみ短いfade、背景src・filterはそのまま|
|停止|120ms|追加暗幕と既存パネルをfade-in。計時は最初に止める|

フル画面高速フラッシュや連続点滅は使わない。prefers-reduced-motionでは変形を止めて状態の静的色差のみ。アニメーション終了イベントを採点・報酬確定の条件にしない。Safari復帰でanimationendが来なくても進行できる。

## 実機での文字と操作

基準キャンバス表示はモックアップ照合用。小さいiPhoneでは中央だけ可変フローにし、44CSSpxタップ範囲を確保。長い文・最大14タイル・2行以上のフレーズ・EASY複合語は見切れをチェック。重なる透明ヒット領域は禁止。無理に文字を小さくせず中央の内部スクロールを使用。背景写真にはblur/filter/tintを適用しない。暗く見せるのは別レイヤーのみ。
