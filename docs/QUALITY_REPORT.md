# Quality verification

実際に納品するPNG・字形フォントを重ねて再構成し、元モックアップと比較しました。ゲームやWebアプリは実装していません。比較はPillowによる画素検証で、iPhone／ブラウザーでの表示テストではありません。

| 画面 | RGB平均絶対差（全体、0〜255） | UI領域の平均絶対差 | 色差16超の画素（全体） |
|---|---:|---:|---:|
| title | 0.3487 | 1.4059 | 0.422% |
| nickname | 1.2823 | 3.3420 | 1.260% |
| member | 0.6572 | 1.2075 | 1.103% |
| background | 1.2828 | 1.6050 | 2.174% |
| home | 0.6003 | 2.5351 | 0.842% |

背景領域の大きさで全体差は小さくなります。上記を「再現率99％」などへ読み替えないでください。元画像と再構成画像、および差分画像を直接確認できるようにしています。

## 保持と検査

- 既存ホームの48ファイルはSHA-256が一致。素材・配置・指示書・比較画像を変更していません。
- PNG 100ファイルをデコードし、破損がないことを確認。
- 新規RGBA 51素材のアルファを検査。写真素材は意図的に不透明です。
- 新規TTF 44ファイルを読み込み、文字マップを検証。
- 人物・背景をAIで再生成していません。人物の写真は元モックアップから分離し、UI外の写真画素は保持しています。
- 動的な文字はPNGラベルにせず、フォントと表示文字として分離。元のバージョン表記・入力カーソル・選択ラベル・サムネイル番号も分離しています。

## 完全一致にならない点

1. 元のレイヤー情報がないため、文字・アイコンの下にあった模様は周囲から補間しています。
2. 透明パネルは色と透明度を解析して分離した素材で、元の制作レイヤーそのものではありません。元の見た目に合うよう写真レイヤーと組み合わせて照合しています。別の写真に載せた際の見え方まで元の未知レイヤーと同一とは保証しません。
3. 固定ラベルの字形を輪郭化したフォントには、元の色の揺らぎ・光・影・アンチエイリアスとの差があります。収録していない文字はフォールバックが必要です。
4. タイトルのロゴと発光は透過抽出しています。ロゴの裏・パネルの裏など元画像で見えない写真は、推定・補間した比較用写真レイヤーです。透過ロゴの輪郭や薄い光には小さな差が残ります。
5. 背景選択の写真小片は完成モックアップの検証用です。提供予定の元写真22枚へ差し替えると小さな写真内容は変わる場合があります。位置・枠・ボタンは維持します。

## 比較ファイル

- `mockups/`：決定済みモックアップ5枚。
- `qa/title/`、`qa/nickname/`、`qa/member/`、`qa/background/`：再構成・原寸差分・差を4倍強調した差分。
- `home_approved/qa/`：承認済みホームの比較一式。
- `qa/all_screens_preview.jpg`：5画面の再構成一覧。
- `qa/asset_transparency_sheet.png`：新規装飾素材の透過確認一覧。
- `qa/file_validation.json`：画像・アルファ・字形フォントの検査詳細。
- `qa/home_preservation.json`：既存ホームファイルの保持確認。

背景選択画面のUI境界付近には、UI領域の矩形の外にも最大13／255の小さな差があります。人物を再生成した差ではなく、透過分離・境界の補間に伴うものです。
