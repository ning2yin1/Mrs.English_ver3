# リザルト実装・確認

## 既存処理との照合

- `src/play/store.js`の`settle()`が10問目のNEXTで精算し、既存`mrsEnglishV3.play.v1.results[stageId]`へ確定結果を保存。wallet、日次回数、最高記録、session完了を共通journalで一度だけ確定する。本体は変更していない。
- `src/play/scoring.js`の`scoreAnswer()`は基本・速度・コンボ・スキル純増の正確な整数単位を各問に保存。`summarize()`が未丸め合計、デッキ点、最終half-upを確定。既存実効果+8%/+6%を維持し、制作画像の+5%/+20%を実カードへ適用していない。
- 平均回答時間は正誤を問わず10問の`elapsedActiveMs`合計÷10。停止・非表示・回答後待機は既存の計時方式で除外される。欠測なら「—」。
- 開始時の`deckSnapshot`と`backgroundId`を使用。現在装備を再取得せず、直前と同じ原写真・cover・centerを維持し、結果だけ独立60%暗幕へ切替。

## 変更ファイル

- `src/result/model.js`: 確定済み結果を読む純粋アダプター。5評価、成績、報酬、開始時装備。精算済み情報/整合性を検証し、架空の数値で埋めない。表示5内訳は正確な整数単位を切捨て、小数部の大きい順に最終スコアとの差を配分（同率は基本→速度→コンボ→スキル→デッキ）。採点/残高/最高記録に書き戻さない。
- `src/result/view.js`, `style.css`: 承認画像1536×710の通常/カウント/確定表示。既存の同一PNGとカード描画を再利用。評価5種類だけキットPNG、FXはキットSVG。全画面画像や透明ボタン背景は使用しない。数字は実テキスト。短い横画面では44pxボタン、14px内訳、12px補足を維持し、内訳だけ内部スクロール。スコア・評価・正解数を優先する。
- `src/result/animation.js`: 単一RAF/performance.nowと設定配列で約3.8秒。基本→速度→コンボ→スキル純増→デッキ、実発動カード/全装備の発光、数値衝撃/光輪/粒子、5評価、左欄への収束、報酬/操作表示。音は実装しない。将来用`result:sync`イベントを一度だけ発行。スキップ時は過去の音イベントをまとめて再発行しない。
- `src/play/view.js`: 旧仮完了表示をResult部品へ置換。
- `src/play/controller.js`: 結果のスタイル/フォント読込と独立レイアウト、演出の開始/破棄。「もう一回」は既存`start(categoryId,difficulty,revision)`へ接続し新stageId。「ステージ選択」は既存dismiss→READY、「ホーム」は既存TOP。精算APIを再呼出ししない。
- `scripts/build.mjs`: result/reusedの無変更コピーは公開せず既存パスを使用。新しいranks/fx/ソースは既存の内容ハッシュ付きPWAキャッシュへ自動登録。
- `scripts/serve.mjs`: SVGにimage/svg+xmlを設定（ローカル開発用）。
- `dev/result.html`, `dev/result.js`: 承認サンプル24527/900のメモリ限定QA入口。実カード/財布への投入なし、公開成果物に含まれない。
- `tests/result-model.mjs`, `tests/result-browser.mjs`, `scripts/compare-result.py`, `qa/result/`: 数値・動作・画像比較。
- `package.json`: `npm run test:result`を追加。

## 中断・スキップ・保存

表示開始は既存精算成功後のみ。読取/演出/再表示/スキップは保存APIを持たず、報酬を再計算・再加算しない。スキップのpointerupとそのclickを消費し、ボタンは次の独立pointerdown/upから有効にする。時間だけのdebounceには依存しない。再プレイ開始中は同期的に操作をロック。旧結果は履歴に保持する。

動き低減は完成表示へ直行。背景化でRAFを停止して完成値へ、破棄時はRAF・イベント・ResizeObserverを解除。新しい保存キー、通貨管理、スコア計算、日次判定は追加していない。

## 検証

- 正解0/4/5/6/7/8/9/10の評価境界、未完了/不正値の拒否、0点/小数/大きな数、整数配分の合計一致、欠測時間「—」。24527=15000+4500+2750+1650+627、報酬900のキット例。
- 5評価の実描画、自然な完走、各加算/確定/収束/ボタン出現区間のスキップ、再表示・リロード・背景化・動き低減でもwallet/カード/レベル/装備/確定結果の文字列が不変。
- 再プレイの新ID/同一文法・難易度、ステージ選択/ホームへの遷移、44px操作域、844×390/667×375の模擬セーフエリア。平均/最大コンボを含む全成績表示。
- 承認3画像との比較は`qa/result/index.html`。3状態の画像比較は同じQAサンプル。実際の確定結果を使った演出も別に撮影・検証している。撮影専用ブラウザーで一時的にRAFを止めて短い演出を記録するが、製品側の進行は変更しない。
- 既存の初期設定・TOP・Collection・Inventory・Shop/ガチャ・3難易度プレイ・最高点/残高・オフライン動作も回帰確認。
