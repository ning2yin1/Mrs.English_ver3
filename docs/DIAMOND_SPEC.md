# ダイヤ・Rコイン追加仕様

ダイヤは非課金通貨。入手元はログインボーナス、デイリーミッション、ウィークリーミッション。ログインボーナスの具体量/導線は本依頼では未定義。既存実装を確認し、不要な変更や追加の自動配布を行わない。

## 交換

|入力|出力|方向|
|---|---|---|
|ダイヤ10個|1,000 Rコイン|ダイヤ→Rコインのみ|

基本単位は1回10個。今回複数口購入や逆交換を新規提案しない。所持ダイヤ9以下は不可、10なら残0かつR+1,000。UIのdisableだけに頼らず確定処理内で最新残高を検証する。

操作IDを作り、排他/トランザクション内で未処理を確認→残高検証→ダイヤ-10とR+1,000と処理済みIDをまとめて確定保存。同一操作の再試行は同じID。二重タップ・通信再送・再起動で二重交換をしない。保存失敗なら片側だけ増減しない。通知完了を交換完了条件にしない。

交換画面の画像は承認されていない。既存Shop/通貨詳細等で実現できるかCodexが調査し、入口・確認UI・残高表示を既存パターンへ合わせる。新画面のレイアウトをこのキットから決定しない。接続先が無い場合は追加実装項目として配置候補を報告する。

## 高ランク強化

|レアリティ|既存Rコイン必要額|追加ダイヤ消費|
|---|---|---|
|R|既存計算をそのまま使用|5個/強化成功1回|
|S|既存計算をそのまま使用|3個/強化成功1回|
|A|既存計算をそのまま使用|0個|
|B|既存計算をそのまま使用|0個|
|C|既存計算をそのまま使用|0個|

既存の強化1回の意味/レベル増加単位を調査。レベル上限、既存コイン不足、追加ダイヤ不足のいずれでも強化不可。まとめ強化等が存在する場合のダイヤ回数は本依頼で未定義なので独断で倍率を決めず確認する。レベル上限や既存能力計算・コイン額を変更しない。

最新のカード個体/レベル/ランク/残高を排他内で確認し、Rコイン減算・ダイヤ減算・既存レベル/能力更新・操作ID・W05の成功回数/新達成報酬を一貫して確定する。少なくとも同じ確定操作を再処理して二重減算/二重W05更新しない。レベルだけ増えて通貨未消費、ダイヤだけ消費、成功前にW05だけ加算する状態を作らない。

強化でW05を達成してダイヤ20の全達成ボーナスも得られる場合でも、支払い能力は報酬付与前の残高で検証する。未来のミッション報酬を先借りして不足強化を許可しない。

## 既存機能保護

唯一の既存通貨残高を使用。旧セーブでダイヤキーが本当に無い場合だけ0を追加し、既存値を0に戻さない。開発用10枚、無料10枚パック受領フラグ、通常抽選/確定枠、カード個体ID、育成値を維持。通貨アイコンと共通残高表示は同じ変更通知に追従させる。通常ガチャの価格・確率・購入通貨は変更しない。
