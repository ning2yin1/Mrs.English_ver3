# Codex向け実装仕様

これは将来の実装指示です。本キット自体にはアプリ実装コードを含めません。qa/inventory/reconstruct.pyは画像検証専用で、ゲーム・ブラウザ・保存領域を操作しません。

## 保護範囲と素材優先

既存TOP/CollectionのUI・配置・表示・挙動・初期設定フローを変更しない。共有PNGを上書きしない。Inventoryだけに閉じた画面、状態管理、CSSを将来追加する。既存Inventoryボタンの現在の遷移先を確認し、その経路を新画面へつなぐ最小の接続に限定する。共有の広範囲リファクタリングは禁止。

新規素材はassets/inventory、配置はlayouts/inventoryを使う。UIパネル・ボタンのグラデーション/光沢をCSSで描き直さない。CSSは配置・クリップ・独立文字・状態・アニメーションに使い、9-sliceは指定値を守る。通常DOMを使ってもカード・写真・枠の画像そのものは変更しない。全画面PNG+透明クリック領域方式は禁止。

## 画面遷移・操作

1. TOPの既存Inventoryボタン→Inventoryメイン。戻る→既存TOP。
2. メイン→デッキ編成：保存済みdeckをdraftDeckへ複製。枠を選択→候補個体を選択→3枠の一意性と所有を再検証→編成確定で保存しメインへ戻る。確定前の戻るではdraftを捨てて保存済み編成を維持する。
3. メイン→カード強化：選択instanceIdを受け取り、最新残高・level・定義から変更前後を表示。ボタン1回で1レベルだけ上げる。上限/所持不足/保存中は実行禁止。保存成功後に同じ画面の現在値・次のプレビュー・残高を更新。戻るとメインのレベル/総合力も最新になる。
4. 右リストだけ縦スクロール。タイトル/デッキ/右見出し/下部操作は固定。詳細なタップ範囲はJSON。ドラッグ中のタップ抑止、メインへ戻ったときの選択・スクロール復帰を行う。

## 選択・編成・強化の状態

- 通常：原写真+原枠。レアリティ記号は原枠のまま。
- 選択中：selection_glow_136/238をカードの後ろに配置。文字は別。発光を写真に直接焼き込まない。
- ほかの枠で編成中：カードの上にRGBA(7,12,35,115)の表示用オーバーレイ、tag_usedと「ほかの枠で編成中」。写真ファイル自体の加工は禁止。aria-disabled/操作拒否も実装する。
- 上限：level=cap。現在と強化後の数値を同じ値にし、必要コイン/強化後残高は「—」として支出なしを示す。ボタンは同じ青PNGをopacity .45、ラベル「レベル上限」、disabled。
- コイン不足：プレビューの能力値は表示しても確定不可。費用を淡赤(#ff9da5)、残高の強化後欄は「—」、ボタンはopacity .45「Rコイン不足」、disabled。負の残高を保存しない。
- 保存中：ボタンopacity .65「強化中…」、二重タップ禁止。失敗時は現在level/残高を変えず既存のエラー表示方式に合わせる。

## 調整可能な定義

最大レベルはユーザー確定仕様のR50/S40/A30/B20/C10。それ以外の能力増加・費用・スキル効果量は例示で、data/inventory/*.example.jsonに分離。計算式を画面内にハードコードしない。同じ人物のカードでもcatalogId別の能力/skillを設定でき、強化してもrarity/catalogId/写真/枠/初回入手日は変えない。

一覧は個体ごとに表示し、同一catalogの複数個体はそれぞれlevelを持つ。Collectionの種類別表示/数量集計は既存仕様を維持する。Inventoryで未所持を表示しない。実データ0枚の場合は同じパネルに空の文言と無効操作で対応し、承認画像の10枚を本番の代用品にしない。

## 実装接続時の確認

DATA_AND_SAVE.mdを優先し、最新版の所持台帳・Rコイン保存場所・既存ルーターをまず読み取る。今回GitHubを確認していないため、過去キットの推奨キーを現行実装の事実として扱わない。既存の窓口が使えるならそこへ接続し、TOP/Collectionの画面コードは変更しない。接続口がない場合は既存表示や保存を推測で書き換えず、必要な最小接続箇所を報告する。

追加フォルダ例はsrc/inventory（将来）に限定。グローバルbodyのoverflowや共通タッチ設定を変えず、Inventory内のviewportにoverflow-y:autoとtouch-action:pan-yを指定。既存のビルド/SW生成処理が追加assets/layouts/dataを扱うかは実装時に確認し、必要な変更だけを別途示す。本ZIPに既存ビルド設定の上書きは含めない。
