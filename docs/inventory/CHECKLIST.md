# 実装後の確認項目

このチェックリストはCodexの将来実装用です。未実装の操作が既に検証済みという意味ではありません。

## 外観

- [ ] 1844×853で各PNG/文字の位置・サイズを承認画像と比較
- [ ] タイトルバー・青ボタン・人物・枠・背景が既存原本のまま
- [ ] 写真/枠の縦横比、9-sliceの角、選択発光の余白が維持される
- [ ] 指定フォント読込後も文字の改行/0.5pxのずれ/重なりがない
- [ ] iPhoneの左右向き・safe-areaで固定UIが切れない
- [ ] 元モックアップや再構成PNGをランタイム背景として使っていない

## 一覧・編成

- [ ] 0/1/10/100個体で所有だけ表示し、件数とCollection数量が一致
- [ ] カード一覧だけ縦スクロールし、名前/ラベル/発光も一緒にクリップ
- [ ] スクロール後に意図しないカード選択が発生しない
- [ ] 選択対象/スクロール位置が強化・編成から戻っても保たれる
- [ ] 枠選択→候補→右上情報/総合力/発光が同一draftから更新
- [ ] 同じinstanceIdの重複をタップと確定時の両方で拒否
- [ ] 同じcatalogIdの別instanceIdは編成可能
- [ ] 未確定で戻ると保存済みdeckを変更しない
- [ ] 確定後の再起動でも3枠/レベルが保持される

## 強化・保存

- [ ] R50/S40/A30/B20/C10を超えず、上限ボタンが無効
- [ ] コイン不足は無効で負残高にならない
- [ ] 費用ちょうどの残高では1回成功して0になる
- [ ] 1タップでlevelが1だけ増え、rarity/写真/初回日/所有数量は変わらない
- [ ] 二重タップ・連打・途中リロード・保存失敗で二重減算/片方だけ保存が起きない
- [ ] メイン総合力と各画面の残高が保存結果から更新される
- [ ] 不正JSON/未知version/未知catalog/未知フィールドを削除・初期化しない
- [ ] 既存TOP/Collection/初期設定/プロフィール保存へ回帰差分がない

## 開発用カード

- [ ] 開発時だけ明示的に有効化。正式版は既定false
- [ ] 所有0枚の初回だけ10枚・3枠を設定し、2回目に増えない
- [ ] 所有ありではカード/編成/レベル/残高を上書きしない
- [ ] 中途失敗の再実行でも同じgrantId/instanceIdで重複しない
- [ ] 正式無料10枚パックの受取履歴と混同せず、Shop処理は今回作らない
