# 素材・再構成検証

今回添付された最終承認PNG3枚を基準とし、独立PNG、既存共通素材、原写真/原枠、独立フォント文字、クリップ・状態から再構成しました。全画面画像を敷く方法は使用していません。

|画面|平均絶対RGB誤差(0〜255)|最大チャンネル誤差|差がある画素|
|---|---:|---:|---:|
|main|0.0|0|0|
|deck|0.0|0|0|
|upgrade|0.0|0|0|

3画面とも、このPillow画像合成条件では全画素一致です。再構成画像と4倍強調差分をqa/inventoryへ同梱。黒一色の差分は一致を示します。画像の位置、サイズ、質感、人物、フレーム、文字、半透明表示、候補の無効状態を目視でも確認しました。

7点の新規装飾PNGには文字/数値/人物/カードを含めず、透過タグと発光はRGBAを保持。背景用backplateだけは元が不透明で、画面ごとの指定opacityで重ねます。25点の既存依存ファイルはhash一致を確認し、再収録・上書きしていません。写真・枠のファイルそのものは読み取りだけです。

日本語フォントを軽量サブセット化した試行では、小サイズの文字の端やヒンティングが変化したため採用せず、承認時フォントを保持しました。ボタン文字の0.5px座標を整数化するずれも修正し、最終の全画素一致を確認しています。

この検証は画像QAです。ブラウザ/iPhoneでの文字アンチエイリアス差や、スクロール・編成・強化・保存の操作は、ゲーム未実装なので検証していません。CHECKLISTは将来の実装確認用です。今回GitHubや公開環境はアクセス・変更していません。

再構成を再実行するには、既存依存素材が揃ったリポジトリへ本ZIPを展開した後に実行します。

```sh
python -m pip install -r qa/inventory/requirements.txt
python qa/inventory/reconstruct.py --root . --out /tmp/mrs-inventory-qa
```

画像だけを出力する検証ツールです。ローカル保存データやゲームに触れません。
