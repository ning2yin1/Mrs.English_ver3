# 納品キットの検証記録

2026-11-02作成。これは素材・仕様の検証であり、既存アプリへの実装試験ではありません。

## 実施済み

- 確定12件のID・名称・達成条件・目標・報酬を照合。日次1,500 R/5ダイヤ、週次7,000 R/20ダイヤ。
- 既存PNG8点の元バイト一致、画像読込、RGBA7点の透明/不透明アルファを確認。背景1点は意図的な不透明画像。
- 新規SVG1点は有効なXML/SVG。背景要素なし、currentColor使用。
- 承認済みJPEG3枚は1536×710、添付原本とバイト一致。再圧縮なし。
- CSSの全画像参照先が存在。括弧整合と状態・進捗変数・スクロール・pointer-events・低モーション設定を確認。
- 納品ファイル名は英数字・ハイフン・アンダースコア・拡張子のみ。人物写真の独立実行素材、アプリJS、不要な一時ファイルなし。

## CSS表示検証の範囲

承認画像と元の装飾素材を目視確認し、座標・9-slice・縮小時の制約を仕様化しました。CSSの参照/構造は検証済みです。この作業環境には実行できるChromiumがないため、ブラウザでの最終合成・iPhone Safariでの実機表示は未検証です。CSS実装後はIMPLEMENTATION_CHECKLIST.mdに従い1536×710、小型横画面、ノッチ、長文通知で調整・確認してください。新たな承認モックアップは制作していません。

## 機能検証の範囲

ミッション判定、期間更新、原子的保存、通知キュー、ダイヤ交換/強化は仕様のみです。既存コード未調査のため、架空APIを確定していません。実装時には既存方式へ接続して二重付与・失敗復旧・既存セーブ維持をテストする必要があります。交換UI、ログイン配布量、まとめ強化単位は未確定として明記しました。

## ZIP

全ファイルは単一ルートmrs-english-mission-kit/内に格納。全ファイルSHA-256をchecksums.jsonに記録（このチェックサムファイル自身は対象外）。ZIP読込・CRC・ファイル数・パストラバーサル不在を検証して納品します。GitHubアクセス、アプリ改変、デプロイは実施していません。
