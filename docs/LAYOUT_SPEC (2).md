# レイアウト・CSS適用仕様

## 基準と責務

基準1536×710。承認済みJPEG3枚は無加工の比較資料。画面全体を単一画像にしない。既存フォントを再利用し、日本語の太さ450/650程度。人物写真はTOP既存表示を維持。Mission本画面は既存の紫青装飾背景を使う。

CSSは`.me-mission`と`.me-mission-toast`内へ限定。タイトル・数値・報酬・行名を画像化しない。日次/週次は同じレイアウトを使い、タブ/データだけ切替。

## DOM/CSS契約（構造のみ、アプリ実装は含まない）

- 画面ルート`.me-mission`
  - `.me-mission__header`：backボタンと既存矢印画像、title、subtitle、automatic
  - `.me-mission__toolbar`：tabs内にtabボタン2個、summary
  - `.me-mission__list-frame`：固定フレーム
    - `ul.me-mission__list`：スクロール対象
      - `li.me-mission__row[data-state="untouched|in_progress|completed"][data-bonus="true|false"]`
        - `.me-mission__text`：name、condition
        - `.me-mission__progress`：progress-value、track内fill
        - `.me-mission__reward`：reward-icon、reward-amount、reward-unit
        - `.me-mission__state`：完了時だけcheck＋状態文字
  - `.me-mission__footer`：左説明、右説明
- 共通シェル`.me-mission-toast[data-phase]`：toast__check、toast__title、toast__divider、toast__name、toast__divider、toast__reward（画像＋テキスト）

上記省略名はすべて同じ接頭辞を付ける。例`name`は`.me-mission__name`。通知は`toast__name`を`.me-mission-toast__name`とする。

タブは実button、aria-selectedで青切替、role=tablist/tab/tabpanel等は既存UI方式に合わせる。行は押して報酬を受け取るボタンではなく一覧。進捗はrole=progressbar、aria-valuemin=0/max=目標/now=現在を付与。状態文字も表示し、色だけで区別しない。

`--progress:60%`のように算出済みの割合をfillへ渡す。小さい値や超過値は0〜100%へ制限。SVGチェックはインラインまたはCSS maskでcurrentColorを適用する。外部imgのSVGへ親colorが伝わると仮定しない。装飾アイコンはaria-hidden、報酬は通貨名込みの読上げを別途付ける。

## 端末サイズ・セーフエリア

- `--u = min(安全な横幅/1536, 安全な高さ/710)`。基準では1px。端末のCSSピクセルとデザインpxを混同しない。
- タップ対象44CSSpx以上、本文16/補助13CSSpx程度の下限を守る。全画面に一括transform:scaleを掛けて文字・タップを小さくしない。
- `100dvh`を優先し、CSSには100vhフォールバック。既存アプリが独自viewport高さを使っていればそれへ合わせる。
- env(safe-area-inset-*)をルートで一度加算。既存シェルが処理済みなら本CSS変数を0pxへ上書きし、二重余白を防ぐ。
- タイトル・タブ・フッターは固定、リストだけflex:1/min-height:0/overflow-y:auto。通知やTOP全体をスクロールさせない。
- 1536×710では6行。844×390/852×393等では行高下限を守り一覧のみスクロール。6行のためにフォントを極端に縮めない。
- 幅1000以下で中央ヘッダー説明を非表示。740以下で行を2段グリッドへ。名前が長くても折返し可能、数値や報酬を隠さない。横スクロール禁止。
- 新カテゴリ等は今回追加しない。日次/週次切替時のスクロール位置は別々に保持可能、報酬付与し直さない。

## 9-slice

CSS内URLはstyles/からの相対パスで一致。青素材slice上18/右20/下17/左20、紫16/18/16/18、一覧フレーム16/16/16/16。sliceは元画像ピクセル、表示border-widthは基準uに応じて縮める。中央はfill/stretch。タブ文字は別HTML。タイトルバーは既存ヘッダー処理を優先し、同梱CSSの背景指定は単独利用時の参照。
