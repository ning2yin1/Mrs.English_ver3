# 素材一覧と対応

実行用画像は9点：既存PNG8点（バイト一致の再収録）、新規SVG1点。新規人物/背景/カードの生成・切り出しなし。複雑な装飾はすべて承認画像の制作時に使った既存素材そのものです。同じ共通素材が既存リポジトリにある場合、そちらを参照し、同梱コピーを本番へ重複配置しないでください。

各PNGの元パス・寸法・SHA-256は`asset_sources.json`。元パスは本制作の保管パスであり、既存リポジトリの実在パスと断定しない。Codexが同一ファイルを探して対応付ける。

## CSSで再現するもの

|対象|方法|
|---|---|
|通常/完了切替|同じ独立行の背景疑似要素を紫.30/青.50へ切替、テキスト不透明度は維持|
|6行目|通常紫背景＋金1px枠/上辺1px、タイトルと数量が金|
|進捗|暗いトラック、1px枠、割合で伸びるシアンfill（ボーナスは淡金）|
|通知背景|濃紫rgba、1px青紫枠、薄い上辺、radius5。横に伸びるflex|
|通知区切り|高さ22/幅1の淡紫線|
|通知動作|opacity＋translateY、約3秒保持|
|数字・ラベル|すべてHTML。3桁区切り、通貨種別はアイコン＋文字|
|タブ文字|HTML、背景のみ既存9-slice|

通知専用背景画像、進捗バー画像、報酬数字画像は不要なので収録していません。通知背景用の空フォルダも作りません。背景PNG以外のPNGは元のRGBAを維持しています。透過箇所がある素材はアルファを確認済み、チェックSVGは背景透明です。切り抜き人物や焼き込み文字を含む行背景はありません。
