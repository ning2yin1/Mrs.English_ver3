# Mrs. English Ver.3 — 英文問題データ No.01〜40

40文法 × 10例文 = **400問**。EASY（4択穴埋め）・NORMAL（並び替え）・HARD（ダミー単語2個入り並び替え）に対応。

- `grammar_01_40.json`: 40カテゴリ・400問の全データ。
- `categories[].questions[].english/japanese`: 元の英文と和訳。
- `easy.prompt`: `_____` の箇所が穴埋め。`options` は4択、`answer` が正解。
- `normal.tiles`: 正解の並び順で保持。**表示時にはシャッフルする**。
- `hard.tiles`: 正解の単語タイル。`distractors` を混ぜてシャッフルする。
- `answer_order`: 正しいタイルのインデックス。重複する単語はタイルIDで管理する。
- `explanation`: 文法項目ごとの簡潔な説明（個々の例文に最適化された解説ではありません）。
- `grade_is_provisional`: No.21〜40の学年は仮分類。確定する際は教科書・カリキュラムに合わせて調整。

## 重要：公開・実装前のレビュー

No.01〜03は先行承認された試作JSONをそのまま採用。No.04〜40のEASY正解箇所・誤答候補・HARDのダミー語・説明は**規則ベースで自動生成した初稿**です。プログラムによる件数・構造検証は済んでいますが、英語教材として自然な選択肢や解説かどうかの**全件目視校正は未実施**です。特に冠詞、代名詞、固有名詞を含む問題と複合語の穴埋めはレビュー推奨。

元データは添付の「英語例文.pdf」（No.01〜22、24〜36）と、この会話で提供されたNo.23、No.37〜40です。PDF抽出由来の空白・句読点には差が残る場合があります。既存データを破壊しないよう、Codex実装前に取り込み方法を確認してください。
